|---|---|---|

| `--color-emerald` | `#10B981` | Accent, success, CTAs, badges |
| `--color-emerald-soft` | `#ECFDF5` | Accent backgrounds |
| `--color-ink` | `#0F172A` | Body/headline text (NOT used as bg) |
| `--color-slate` | `#475569` | Muted text |
| `--color-mist` | `#64748B` | Subtle text |
| `--color-line` | `#E2E8F0` | Borders, dividers |
| `--color-cream` | `#F8FAFC` | Page background |
| `--color-cloud` | `#F1F5F9` | Section background / cards alt |
| `--font-display` | `Sora, sans-serif` | Headlines |
| `--font-sans` | `Inter, sans-serif` | Body |

**Gradients**: `--gradient-brand: linear-gradient(135deg, #1E3A8A 0%, #2547A8 40%, #38BDF8 100%)` and `--gradient-emerald: linear-gradient(135deg, #10B981 0%, #34D399 100%)`. Used sparingly on hero blob, primary buttons, and gradient text.

**Shadows**: Soft, layered, premium — `shadow-card: 0 1px 2px rgba(15,23,42,.04), 0 8px 24px rgba(30,58,138,.06)`, `shadow-float: 0 20px 50px rgba(30,58,138,.10)`, `shadow-glow: 0 0 40px rgba(56,189,248,.25)`.

**Radii**: `rounded-xl` (16px) default for cards, `rounded-3xl` (28px) for hero/large cards, `rounded-full` pills.

**Spacing rhythm**: 8px base, generous whitespace (sections `py-24 md:py-32`, containers `max-w-7xl mx-auto px-6`).

### Typography Scale
- Display: Sora 700/800, sizes clamp (e.g. hero `text-5xl md:text-7xl`)
- H2 sections: Sora 700 `text-3xl md:text-5xl`, tight tracking
- Eyebrow labels: Inter 600 uppercase `text-sm tracking-widest` in royal/emerald
- Body: Inter 400/500 `text-base md:text-lg leading-relaxed` in slate

## Animation Principles (framer-motion)
Shared variants in a new `src/lib/motion.js`:
- `fadeUp` — opacity 0→1, y 24→0, 0.6s `easeOut`
- `staggerContainer` — staggerChildren 0.12
- `fadeIn`, `scaleIn`, `slideInLeft/Right`
- All triggered by `whileInView` with `viewport={{ once: true, margin: "-80px" }}`.
- **Float**: looping `y` oscillation (±10px, 6s) for hero floating cards & blobs.
- **Parallax**: `useScroll` + `useTransform` on hero visual & portfolio images.
- **Counters**: custom hook using `useInView` + `animate()` from framer-motion.
- **Magnetic hover** on buttons (subtle translate toward cursor).
- **Respect `prefers-reduced-motion`**: disable float/parallax; keep fades.

## Responsive Strategy
- Breakpoints: `sm 640`, `md 768`, `lg 1024`, `xl 1280`.
- Mobile-first; hero stacks (text → visual), nav → sheet, service blocks stack, bento → single col, masonry → 1–2 cols, timeline → vertical, footer → stacked.
- Touch targets ≥44px, no hover-only interactions on mobile (hover effects degrade gracefully).
- Images: responsive `sizes`, lazy-loaded (`loading="lazy"`), width/height to prevent CLS.

## Accessibility
- Semantic landmarks (`header/nav/main/section/footer`), `aria-label`s on icon buttons, accordion `aria-expanded`, form labels, focus-visible rings (royal), color contrast AA+ (ink on cream, royal on white), `prefers-reduced-motion` respected, alt text on all images.

## Performance
- Drop 12.8MB video. Use CSS/SVG illustrations (no heavy assets). Lazy-load below-fold images. framer-motion `once: true` reveals. Code-split routes (React.lazy) optional. Font `display: swap`. Target LCP < 2.5s.
